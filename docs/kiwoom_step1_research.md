# STEP1 후속 조사: 모의투자와 남은 제한

2026-09-11 공식 문서 조사. 실제 계좌/모의투자 서버는 호출하지 않았다.

## 모의투자 준비

[키움 발급 안내](https://openapi.kiwoom.com/intro/serviceInfo)에 따르면 실전과 모의투자의
App Key는 별도 관리한다. 모의투자 App Key 관리에서 계좌와 허용 IP를 등록하고 별도 키를 발급한다.
[모의투자 안내](https://openapi.kiwoom.com/intro/mockInvestInfo?dummyVal=0)는 미국주식 모의투자 별도 신청,
NYSE/NASDAQ/AMEX 지원 및 무료 실시간 시세를 안내한다.

기존 테스트의 '모의 응답'은 테스트 코드가 생성한 HTTP 응답이다. 키움 모의투자 실연결 검증과 다르다.
사용자가 모의투자 키를 발급해야 외부 모의투자 API 테스트를 진행할 수 있다.
키를 채팅이나 Git에 넣지 않는다. 별도 권한 600 자격증명 파일에 mode=mock을 사용하고
실전 account2 프로필 파일을 덮어쓰지 않는다. 실제 모의 주문도 조회 테스트와 구분해 범위를 정한다.

## 조사 결과와 다음 검증

| 제한 | 공식 자료에서 확인한 것 | 남은 검증 |
|---|---|---|
| 현금/예약금 | ust31490에 주문가능현금 및 미수불가 금액/수량이 있어 STEP1에 구현 | 미체결·부분체결·취소 전후 예약금/수수료 변화. 명세에 산식은 없음 |
| 과거 미체결 | ust21180은 시작·종료 주문일자와 각 행 ord_dt, 잔량 제공 | 조회 보존기간, 예약/장기유효 주문의 날짜 경계, 누락 없는 전체 범위 |
| 시세 시각 | usa20100 명세에는 현재 체결의 원시각 필드가 없음 | 기존 응답에 단순 시각 파서를 추가하는 방식으로 해결 불가 |
| 대체 시세 | FE에 20(시간), 22(체결일자), 51020(현지 체결시간) 존재 | 시간대·일자 결합, DST, 지연/역순/재접속, 서버와의 시계 차이를 모의 시세로 검증 |
| 소유 범위 | API 계좌 잔고로 전략별 소유수량은 구분되지 않음 | 사용자 전략 범위 또는 별도 원장이 필요. 조사로 임의 결정할 수 없음 |

공식 API 경로:

- [ust31490](https://openapi.kiwoom.com/m/guide/apiguide/38/ust31490)
- [ust21180](https://openapi.kiwoom.com/m/guide/apiguide/32/ust21180)
- [usa20100](https://openapi.kiwoom.com/m/guide/apiguide/33/usa20100)
- [FE 실시간 체결가](https://openapi.kiwoom.com/m/guide/apiguide/40/FE)
- [usa20150 상세 체결](https://openapi.kiwoom.com/m/guide/apiguide/33/usa20150): cntr_tm은 HHmmss이나 이것만으로 날짜/시간대를 추정하지 않는다.

모의투자 키 확보 후 읽기 검증을 먼저 수행한다. 예약금 의미는 별도 승인된 모의 주문에서
미체결 → 부분체결/체결 → 취소 상태별 원금·현금·최대수량 변화를 관찰하고,
공식 산식 설명이 필요하면 키움에 질의한다. 모의 결과가 실전과 같다고 자동 간주하지 않는다.

현재 실주문 차단을 유지한다. STEP2 스캐너 MCP와 키움 모의투자 키는 서로 무관하다.
