ust31490의 100.00 USD는 요청 형식 검증용 지정가다. 현재 시세나 주문 계획이 아니다.
모의 서버에서 이 API가 지원되지 않아 실제 주문가능금액/예약금 의미를 검증하지 못했다.
이는 이번 응답에서 확인한 증권사 모의 API 제한이며 코드 오류로 단정하지 않는다.

## 미확인 사항과 다음 검증

- 실제 체결/부분체결/취소/거절 행이 없어 파서의 실데이터 대응은 미검증.
- USD 예수금 행이 없는 이유는 응답만으로 확정 불가. 미국주식 모의투자 신청 및
  모의 USD 자금 설정을 키움 화면에서 확인할 필요가 있다.
- ust31490 모의 지원 여부 및 대체 조회 API는 키움에 확인해야 한다.
  모의 주문을 넣는 것만으로 미지원 API가 지원되는 것으로 간주하지 않는다.
- 예약금/수수료 변화, 날짜 경계, 다중 페이지, 시세 원시각, 전략 소유범위는 미확인.
- 모의 주문 생성은 이번 읽기 테스트 범위에 포함하지 않았다.
- 실전 키로 자동 전환하지 않으며 `validated_for_execution=false`와 실주문 차단을 유지한다.

## 해외주식 모의투자 전용 키 재검증

검증일: 2026-09-12 (KST). 국내 모의투자 키와 분리된
`kiwoom_overseas_mock_profiles.json`의 account2를 사용했다. 모의 서버와 조회 TR만
허용하고 리다이렉트·주문·취소·실계좌 접근은 차단했다.

| 항목 | 결과 | 판단 |
|---|---|---|
| OAuth 인증 | HTTP 200, return_code=0 | 해외 모의투자 키 인증 성공 |
| ust21150 당일·전일 체결내역 | 성공, 각 0건 | 조회 경로 정상. 실제 상태 행 검증은 아님 |
| ust21050 당일 미체결 | 성공, 0건 | 당일 기준 미체결 없음 |
| ust21110 외화 예수금 | USD 주문가능현금 100,000.000 | 해외 모의 계좌 USD 행 조회 성공 |
| ust31490 SPY/NY, QQQ/ND | return_code=20, RC9000 | 모의투자에서 해당 업무 미제공 |

USD 현금 조회 성공은 이전 국내 모의 키에서 없던 자료를 확인한 진전이다. 그러나
`fc_ord_alowa`에 미체결 예약금과 수수료가 어떻게 반영되는지는 여전히 확인되지 않았다.
또한 종목별 주문가능수량 API가 모의투자에서 제공되지 않으므로 주문 직전 수량 대조를
완료할 수 없다. 따라서 `validated_for_execution=false`와 실제 주문 차단을 유지한다.

2026-09-14 재조회에서도 USD 주문가능 현금 100,000, 미체결 0건, SPY 현재가 조회는
성공했지만 `ust31490`은 동일한 `RC9000`으로 거절됐다. 해외 모의 주문 진단기의
`prepare`가 `validated_for_execution=false`를 무시하던 구현 오류를 수정해, 이 상태에서는
주문 계획 생성과 주문 전송을 차단한다.

사용자가 제한을 확인하고 명시적으로 승인한 1주 진단은 2026-09-15 정규장에 별도
CLI로 실행했다. SPY 600 USD 지정가 매수는 미체결 1주로 확인됐고, 취소 후 USD
주문가능 현금이 100,000 → 99,394 → 100,000으로 복구됐다. 이 예외는 웹이나 ETF
주문 경로에 연결하지 않았으며 실행 가능 상태로 승격하지 않는다. 주문일자와 취소 상태의
실제 응답 차이는 [해외 모의투자 1주 주문·취소 검증](kiwoom_overseas_mock_order_test.md)에 기록했다.

같은 날 추가 승인으로 SPY 1주 체결 후 1주 매도 왕복과 SPY·QQQ 동시 미체결을
검증했다. 왕복 거래 뒤 모의 비용 15.233 USD가 반영됐으며, 다종목 미체결에서는
각 지정가의 101%가 누적 예약되고 취소 후 기준 현금으로 복구됐다. 실제 ETF 전체
사이클용 모의 전용 실행 어댑터를 이후 추가했다.

2026-09-15 한 버튼 ETF 최종 점검에서는 SPY·QQQ 목표 1주씩의 격리 사이클을
만들었다. 매도 차액이 없어 주문 없이 잔고·미체결을 확인하고, 현금·최신 가격을
재조회한 뒤 매수 단계로 진행했다. 첫 QQQ 매수가 주문번호 없이 명시적 REJECTED가
되자 SPY는 PREPARED로 남아 전송되지 않았다. 이후 조회에서 주문가능 현금
99,984.767 USD, 열린 주문 0건, SPY·QQQ 각 0주를 확인했다. 장 종료 무렵의
결과지만 상세 거절 사유가 없어 원인을 단정하지 않는다. 가짜 broker 격리 테스트의
정상 전체 완료 경로는 통과했다.

같은 날 23:12 KST 정규장에 다시 실행했다. QQQ·SPY 각 1주 매수와 체결 대조가
모두 성공해 매수 사이클이 COMPLETE가 됐고, 별도 원상복구 차액 사이클에서 각 1주
매도와 체결 대조도 성공해 COMPLETE가 됐다. 시작은 현금 99,984.768 USD,
미체결 0건, 두 종목 보유 0주였고 종료는 현금 99,955.540 USD, 미체결 0건,
두 종목 보유 0주였다. 현금 차이 29.228 USD는 모의 체결 가격·비용 결과이며 실제
수수료율로 해석하지 않는다. 격리 저널은 운영 DB와 분리된 `/tmp` 파일을 사용했다.

## 국내주식 모의 매수·미체결·취소 실연결 검증

검증일: 2026-09-14 (KST). 사용자가 명시적으로 요청한 국내 모의계좌 테스트이며
`kiwoom_mock_profiles.json`의 `account2`, `mode=mock`, KRX에서만 실행했다.
실계좌·운영 DB·운영 주문 화면은 사용하지 않았고 격리된 SQLite 기록을 사용했다.

삼성전자(005930) 현재가 251,500원과 당일 하한가 182,000원을 증권사 조회로 확인한 뒤,
체결 가능성을 낮춘 200,000원 지정가로 정확히 1주를 주문하고 취소했다.

| 단계 | 결과 | 검증 근거 |
|---|---|---|
| 시작 상태 | 주문가능 현금 50,000,000원, 보유 0종목, 미체결 0건 | `kt00001`, `kt00018`, `ka10075` |
| 주문 접수 | 성공, 유효한 주문번호 수신 | `kt10000` 명시적 성공 코드와 주문번호 |
| 미체결 확인 | 매수 1주 중 체결 0주·잔여 1주, 지정가 200,000원 | `ka10075` 주문번호·종목·방향·수량·가격 일치 |
| 예약금 반영 | 주문가능 현금 49,799,300원 | 주문 후 `kt00001.ord_alow_amt` 재조회 |
| 취소 접수 | 성공, 유효한 별도 취소 주문번호 수신 | `kt10003` 명시적 성공 코드와 주문번호 |
| 취소 완료 | 원주문 미체결 목록에서 소멸, 취소 행이 원주문과 연결됨 | `ka10075`, `kt00007` |
| 현금 복구 | 주문가능 현금 50,000,000원 | 취소 후 `kt00001.ord_alow_amt` 재조회 |

검증 중 취소 직후 연속 조회가 HTTP 429 호출 제한을 받았다. 주문이나 취소를 재전송하지
않고 상태를 `CANCEL_SUBMITTED`로 유지했으며, 조회만 간격을 두고 다시 실행해 위 결과를
확인했다. 조회 전용 증거 수집기는 429에서 2·4·8·16초의 제한된 재시도를 하도록
보완했다. 이 재시도 경로에는 주문 API가 포함되지 않는다.

이번 검증으로 국내 **매수 주문 → 미체결 → 취소 → 예약 현금 복구**는 모의계좌에서
확인했다. 매도 주문과 매도가능수량 복구, 실제 체결·부분체결·거절, 장 마감 상태,
가격 단위 자동 산출은 아직 실연결로 확인하지 않았다. 실계좌 주문 허용 근거로 사용하지 않는다.
