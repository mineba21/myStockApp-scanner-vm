# ETF 자산배분 운영 및 인수인계

갱신: 2026-09-15. Codex와 Claude가 다음 작업 전에 읽는 현재 상태 문서다.
상세 근거·테스트 시나리오는 [검토 기록](etf_rebalance_review.md)에 있다.

## 현재 사용자 결정

- ETF 자산배분 계좌는 **account2**다.
- 매월 VAA·LAA·듀얼 모멘텀에서 정한 종목·비율은 그대로 사용한다.
- 이전 전량매도 지시는 2026-09-09 사용자 결정으로 **차액 재분배**로 대체했다.
  예: 10주를 보유하고 목표가 12주면 2주만 산다. 목표가 8주면 2주만 판다.
  목표에서 제외된 관리 ETF만 전량 매도한다.
- 매월 계산된 종목·비중은 사용자가 화면에서 최종 확인한다. **사용자가 `리밸런싱 실행`
  버튼을 누른 경우에만** 해당 사이클의 차액 매도 → 체결 확인 → 실제 주문가능 현금
  재조회 → 차액 매수를 순서대로 진행한다. 월별 계산만으로 주문하는 자동매매는 아니다.
- 버튼 한 번의 승인은 화면에 표시된 한 사이클의 매도·매수 전체 과정에만 유효하다.
  미체결·부분체결·거절·접수 여부 불명·예상과 다른 보유수량이 있으면 다음 단계로
  넘어가지 않는다. 중복 클릭이나 프로세스 재시작은 같은 영속 기록을 이어서 확인하며
  같은 주문을 새로 보내지 않는다.
- 2026-09-15 최신 사용자 결정으로 **account2는 ETF 자산배분 전용 계좌**다.
  관리 범위는 easy/original VAA·LAA·듀얼 모멘텀 후보군의 합집합인
  `AGG, BIL, EEM, EFA, GLD, IEF, IEMG, LQD, QQQ, SHY, SPY, VTV`다.
  이 목록 밖의 종목을 자동 매도 대상으로 확대하지 않는다.

## 구현과 실제 연결을 구분할 것

`trading/allocation_rebalance.py`는 차액 계산, 영속 주문 기록, 단일 사용자 승인,
중복 전송 방지, 매도 체결 대조 후 실제 현금을 다시 조회하는 흐름을 구현했다.
가짜 broker의 격리 테스트로 정상 전체 흐름과 중단 흐름을 검증했다.
`trading/kiwoom_allocation_mock_broker.py`는 키움 모의투자 서버만 허용한다.
`trading/kiwoom_allocation_live_broker.py`는 real `account2`만 허용하며 같은 한 버튼
차액 재분배 흐름에 실계좌 조회·호가·주문·체결 대조를 연결한다. 월간 종목·비중을
사용자가 확인하고 버튼을 누르기 전에는 주문하지 않는다.

실계좌 어댑터는 각 매수 직전에 같은 종목과 지정가로 `ust31490`을 다시 호출해
`min_ord_alowq`와 1% 운영 여유금 적용 수량을 모두 만족할 때만 한 번 전송한다. 각 매도
직전에는 최신 잔고의 `sell_alowq`를 다시 확인한다. 주문 HTTP 타임아웃은 자동 재전송하지
않고 UNKNOWN으로 남겨 주문내역 대조를 요구한다. 최신 근거는
[STEP1 기록](kiwoom_execution_evidence.md)을 먼저 읽는다.

연결 완료에 필요한 근거:

1. 키움 미국주식 미체결·주문체결 내역 API의 요청/응답, 전체 페이지, 거래일·계좌 범위.
2. 주문번호 또는 고유 조건으로 원래 주문과 대조. 타임아웃은 접수 여부 불명으로 유지.
3. USD 주문가능 현금의 미체결 예약금·수수료 반영 의미. 이미 반영한 예약금을 다시 빼지 않는다.
4. 시세 원시각 해석과 60초 유효성 검사. 조회한 현재 시간을 시세 시각으로 대신하지 않는다.
5. 계좌 내 전략 소유범위. 같은 ETF에 다른 전략 수량이 섞이면 별도 수량 원장이 필요하다.

## 설정

- `ALLOCATION_LIQUIDATION_SCOPE`: 이름은 호환 유지. 의미는 전량매도 목록이 아니라
  이 전략이 전용 소유한 관리 ETF 목록. 비우면 위 12종 전체를 기본 사용한다.
- `ALLOCATION_JOURNAL_PATH`: 모든 worker가 공유하는 영속 로컬 SQLite 절대 경로.
  삭제하거나 임시 파일로 바꾸면 중복 방지 근거를 잃는다. 다중 호스트는 별도 설계가 필요하다.
- `ALLOCATION_RESERVE_BPS=100`: 매수 예산의 1%를 남기는 보수적 설정. 증권사 수수료율이라는 뜻이 아니다.
- `ALLOCATION_EXECUTION_MODE=disabled|mock|real`: 기본값은 disabled. mock은 별도 해외
  모의투자 프로필, real은 기본 프로필 파일의 account2를 사용한다.
- `KIWOOM_OVERSEAS_MOCK_PROFILES_FILE`: 모의투자 account2 키 파일. 저장소와 로그에
  키 원문을 넣지 않는다.
