# 국내 종목 목록 조회 복구

HTTP301 리다이렉트가 POST를 GET으로 바꿔 조회 조건이 사라지는 장애를 수정한다.
HTTPS 직접 POST, 리다이렉트 거부, HTTP 상태 및 실제 JSON 목록 검증을 적용한다.
Content-Type은 KRX 정상 JSON에도 text/html일 수 있어 성공 판정 조건으로 쓰지 않는다.
조회는 최대3회, 연결5초/응답20초 제한 및1/2초 간격 재시도한다.
응답 본문 대신 상태·크기·예외 종류만 기록한다. 최종 실패는 DataFetchError로
전달하여 기존 상위 스캔 ERROR 처리로 진입한다. _scan_kr도 빈 목록을 거부한다.
종목 필터와 전략은 그대로 유지한다. 캐시나 다른 목록으로 조용히 대체하지 않는다.
목록 조회 실패 시 해당 스캔의 후속 보유 관측도 실행되지 않으므로 스캔 상태와
B capture 존재를 따로 점검해야 한다. 수동 스캔·주문·발송으로 테스트하지 않는다.
